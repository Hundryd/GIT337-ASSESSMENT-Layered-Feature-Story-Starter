Each layer supports the story and still works without the extra styling.

Header issue badge Shows the edition and adds a magazine feel. It sits in the masthead like normal text. It is positioned to stay aligned without moving the text. Container: .feature-header. Stack: raised behind the title. On mobile it moves below the intro. Check it at 320px, 768px, and 1280px.
Story guide side navigation Helps readers move through the story. It is a normal list of links. It stays sticky on large screens so it stays visible. Container: .story-layout. Stack: sticky. Below 52rem it sits in the normal flow. Test links and sticky behavior.
Feature image with overlay detail Shows the main image and adds a small label. The image sits in the article with its caption underneath. The label is layered over the image without changing the reading order. Container: .feature-figure. Stack: overlay. If the label is hidden, the image still reads clearly. Test hover and reading order.
Pull quote overlap Highlights the main idea. The quote sits between paragraphs like normal text. It overlaps slightly to make it stand out. Container: article section. Stack: raised. On small screens it goes back to full width. Test mobile reading and spacing.
Background texture Sets the mood without making the page hard to read. The page would just be a dark background. A soft fixed texture adds atmosphere behind the content. Container: viewport. Stack: base. If the texture fails, the page still stays readable. Check readability and focus states.
Portrait shape wrap Lets the image sit inside the text more naturally. The portrait would be a normal block image. A float and shaped wrap help the text flow around it. Container: article section. Stack: base. If the shape is unsupported, it still works as a normal float. Test at 200% zoom and without shape support.
Layer scale and focus treatment Keeps the layout accessible and easy to use. Links and controls use the default browser styles. Layer levels stay clear and focus states stay visible. Stack levels: base, raised, sticky, overlay. Without the styling, the content still works. Check keyboard focus and overlap.
